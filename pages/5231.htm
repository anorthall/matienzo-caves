The information for this site has been shared by Guy Simonnot (Simonnot G, 2022) and roughly translated from the Spanish using Google Translate as a starting point. The original grid reference used ED50 datum which has been converted to the ETRS89 datum above, with the altitude taken off the MCP QGIS map.

  Elongated mouth surrounded by trees, which goes down about 9m to a ramp that gives access to a pitch that goes down approximately 21m. The entire cavity is impregnated with the smell given off by different decomposing animals that are in the background, the floor is full of worms. April 3, 2015 Asociación Cientifico-Excursionista de Mataró.
A local named Carlos indicates the existence of the cavity.
