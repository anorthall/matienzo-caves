Area position : Site entrance in context : Logbook search

Updated 5th December 2014

The entrance has the remains of an old wall. The chamber inside contains an excavated slot, 3m beyond which is a dug out inclined rift dropping to the head of a ladder pitch. At the foot is a connection through boulders to site 3938. The grid reference above is from the survey. An alternative grid reference is ETRS89: 30T 447831 4793920.

Reference: anon., 2013e (autumn logbook); anon., 2014d (autumn 2014); anon., 2016b (Easter logbook)
