The information for this site has been shared by Guy Simonnot (Simonnot G, 2022) and roughly translated from the French using Google Translate as a starting point. The original grid reference used ED50 datum which has been converted to the ETRS89 datum above, with the altitude taken off the MCP QGIS map.

     Above the track that goes towards Cullaherboso. To get there, take the path from Bustablado towards Tabladillo and Garma Blanca.
    The entrance, almost blocked by brambles, is a 0.6 x 0.5m opening with a large stone that hides part of the entrance. The torca consists of a single pitch, 16 m deep, without any continuation at the bottom. Various bones and trash take up a good portion of the base.
